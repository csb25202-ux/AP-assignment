# Assignment 1: Time Complexity Analysis

## Question
Write a C program to analyze time complexities in constant time, linear time and quadratic time. Increase the size of input to check the time consumed.

## Objective
To understand and compare:
- Constant Time O(1)
- Linear Time O(n)
- Quadratic Time O(n²)

## Algorithm
1. Execute a constant time operation.
2. Execute a linear loop for different input sizes.
3. Execute a nested loop for quadratic time.
4. Measure execution time using clock().
5. Compare the results.

## Language
C

## Compile
gcc assignment1.c -o assignment1

## Run
./assignment1
